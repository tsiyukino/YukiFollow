# Surface Anchor
anchor.intro = メッシュのシェイプキーが変わっても、このオブジェクトをメッシュ表面に貼り付けたままにします（Blender の頂点ペアレントのように）。シェイプキーを何が動かしていても（メニュー、衣装切り替え、Modular Avatar、VRCFury）位置と傾きが追従します。アバターのビルド時に適用され、エディター上では動きません。
anchor.settings = 設定
anchor.surface = 追従するメッシュ
anchor.surface.tip = このオブジェクトを貼り付けるメッシュ。空の場合はビルド時に最も近いメッシュを使います。
anchor.find_nearest = 最寄りを検索
anchor.follow_rotation = 傾きも追従
anchor.follow_rotation.tip = 移動だけでなく表面の傾きにも合わせます。SPS ソケットでは挿入方向が追従するよう有効にしてください。
anchor.sample_radius = サンプル半径
anchor.sample_radius.tip = 動きを測るために使う、このオブジェクト周辺の表面の範囲。大きいほど滑らか、小さいほど細部に追従します。
anchor.no_surface_now = 5 cm 以内にメッシュ表面がありません。オブジェクトをメッシュ上に移動するか、メッシュを指定してください。
anchor.ignored = 無視するシェイプキー
anchor.ignored.tip = このオブジェクトを動かしてはいけないシェイプキー。* は任意の文字列、大文字小文字は区別しません。
anchor.ignored.sps = 自動で無視（この SPS ソケットの深度アニメーションで動くもの）：{0}
anchor.bind = 配置
anchor.bind.none = 未バインド：ビルド時のシェイプキー値を配置時の値とみなします。
anchor.bind.moved = バインド後に移動されています：現在の位置を現在のシェイプキー値での配置とみなします。「再バインド」で確定してください。
anchor.bind.corrected = 配置後にメッシュのシェイプキー値が変わりました。ビルド時に表面に合わせて {0} mm 移動します（Scene ビューのオレンジのマーカー）。
anchor.bind.ok = 現在のシェイプキー値にバインド済みです。
anchor.rebind = ここで再バインド（現在の位置・現在の値）
anchor.motions = この点を動かすシェイプキー
anchor.motions.hint = どれかがどこかでアニメーションされると、オブジェクトが追従します。値は 100% のときの移動量です。
anchor.motions.none = このメッシュにこの点を動かすシェイプキーはないため、オブジェクトは動きません。
anchor.motion_row = {0} mm · {1}°
anchor.show_all = すべて表示（{0}）
anchor.samples = {1} mm 以内の {0} 頂点で計測しています。
anchor.far = 最も近い表面の頂点まで {0} mm あります。最寄りの表面に追従するため、意図した位置とずれる可能性があります。
anchor.error.no_mesh = 指定したメッシュにメッシュデータがありません。
anchor.error.no_surface = オブジェクト付近の表面頂点が少なすぎます。メッシュ上に移動するか、サンプル半径を大きくしてください。

# Blendshape Sync
sync.intro = アバター上のすべてのメッシュを、素体の同名シェイプキーに追従させます。「Breasts_big」などを持つ衣装や小物が、何が素体を動かしていても一緒に変わります。アバターのビルド時に適用され、シーンは変更しません。
sync.duplicate = このアバターには Yuki Blendshape Sync が複数あります。最初のものだけが使われます。
sync.settings = 設定
sync.sources = ソースメッシュ
sync.sources.tip = 他のメッシュが追従するシェイプキーを持つメッシュ。空の場合はアバター直下の「Body…」という名前のメッシュを使います。
sync.sources.auto = 自動：{0}
sync.sources.none = アバター直下に「Body…」という名前のメッシュがありません。素体メッシュをソースメッシュに追加してください。
sync.excluded_meshes = 除外するメッシュ
sync.excluded_meshes.tip = 自分のシェイプキーを保つメッシュ。
sync.excluded_names = 除外するシェイプキー
sync.excluded_names.tip = 同期しない名前。* は任意の文字列、大文字小文字は区別しません。既定では素体の Shrink 系、口の形、区切り線を除外します。
sync.copy_defaults = シーンの値をコピー
sync.copy_defaults.tip = ビルド時に素体のシーン上の値を追従側にコピーします。
sync.animations = アニメーションに追従
sync.animations.tip = 素体のシェイプキーを変えるすべてのアニメーションに追従側を追加します。
sync.preview = 同期される内容
sync.preview.none = ソースメッシュと同じ名前のシェイプキーを持つメッシュはありません。
sync.preview.summary = {0} 個のメッシュが {1} 個のシェイプキーに追従します。
sync.preview.differs = 現在 {0} 個が異なる
sync.apply_now.hint = 現在 {0} 個の値が素体と異なります。ビルド時にはいずれにせよコピーされます。シーンに適用するとエディター上でも結果を確認できます。
sync.apply_now = シーンの値を今すぐ適用

# Seam Normals
seam.intro = 素体と接する部分で、このメッシュの陰影を素体に合わせます。素体の穴を埋める別メッシュは自分の法線を持つため、ライティングによっては継ぎ目が見えます。アバターのビルド時に、継ぎ目の法線を素体の法線に置き換え、このメッシュ自身の法線へ徐々に戻します。エディター上では何も変わりません。
seam.settings = 設定
seam.surface = 合わせるメッシュ
seam.surface.tip = このメッシュをなじませる先のメッシュ。空の場合はビルド時に継ぎ目に最も近いメッシュを使います。
seam.surface.auto = 自動：{0}
seam.blend_width = なじませ幅
seam.blend_width.tip = 継ぎ目からこのメッシュに沿ってどこまでで自分の法線に戻るか。広いほど柔らかくなります。自分の陰影を残したい部分にかからない幅にしてください。
seam.seam_gap = 継ぎ目の距離
seam.seam_gap.tip = このメッシュの開いた辺が表面からこれより近いとき、継ぎ目とみなします。
seam.no_surface_now = このメッシュの開いた辺の近くにメッシュ表面がありません。合わせるメッシュを指定してください。
seam.preview = ビルド時に行うこと
seam.preview.summary = 継ぎ目の頂点 {0} 個、なじませる頂点 {1} 個。法線の回転は平均 {2}°、最大 {3}°。
seam.error.no_seam = このメッシュの開いた辺が表面から {0} mm 以内にないため、なじませる継ぎ目がありません。合わせるメッシュを確認するか、継ぎ目の距離を広げてください。

# Build errors (NDMF)
error.anchor_failed = {0} の Surface Anchor を適用できませんでした：{1}
error.no_surface = {0} の Surface Anchor：オブジェクト付近にメッシュ表面が見つからないため、何にも追従しません。
error.transform_animated = {0} の Surface Anchor：オブジェクト自身の位置または回転がアニメーションされています。それらは表面の点からの相対になります。意図しない場合は子オブジェクトに移してください。
error.sync_duplicate = このアバターには Yuki Blendshape Sync が複数あります。最初のものだけが使われます。
error.seam_failed = {0} の Seam Normals を適用できませんでした：{1}
error.seam_no_surface = {0} の Seam Normals：開いた辺の近くにメッシュ表面が見つからないため、法線はそのままです。
error.seam_no_seam = {0} の Seam Normals：表面から {1} mm 以内に開いた辺がないため、法線はそのままです。
